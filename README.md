# GitParty

O GitParty é uma plataforma de gerenciamento de eventos de aniversário desenvolvida com foco em organização de festas, cadastro de eventos e gerenciamento de participantes.

O sistema permite:
- cadastrar eventos
- visualizar eventos
- visualizar detalhes do evento
- upload de imagens
- gerenciamento de inscrições
- controle de capacidade máxima
